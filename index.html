งานของฉันอยู่ตรงไหน

แบบสอบถามประมาณ 6 นาที เพื่อดูว่างานปัจจุบันอยู่ตรงไหนระหว่างแกนความแข็งแรงทางการเงิน (X) กับคุณภาพงาน (Y) ทั้งสองแกนมีคะแนนตั้งแต่ −10 ถึง +10 โดย 0 คือจุดกลาง ข้อมูลประมวลผลในเบราว์เซอร์ของคุณเท่านั้น

1. การเงินรายเดือน

2. สิ่งที่คุณให้ความสำคัญ

1 = สำคัญน้อย, 5 = สำคัญมาก ด้านที่สำคัญมากจะมีผลต่อคะแนนคุณภาพงานมากขึ้น

3. คุณภาพงาน

ตอบตามจริงในช่วง 1–3 เดือนที่ผ่านมา −2 = ไม่จริงเลย, −1 = ค่อนข้างไม่จริง, 0 = กลางๆ, +1 = ค่อนข้างจริง, +2 = จริงมาก

4. เกณฑ์ที่ไม่ควรยอมรับ

ติ๊กเฉพาะข้อที่เกิดขึ้นจริง จะถูกเตือนแยกจากคะแนน
