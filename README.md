# งานของฉันอยู่ตรงไหน

แบบสอบถามเว็บไฟล์เดียว (HTML + CSS + JavaScript) ดูว่างานปัจจุบันอยู่ตรงไหนระหว่าง **ความแข็งแรงทางการเงิน (แกน X)** กับ **คุณภาพงาน (แกน Y)** ทั้งสองแกนมีคะแนน −10 ถึง +10 โดย 0 คือจุดกลาง

ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่ส่งข้อมูลไปที่ใด ผลเก็บใน localStorage ของเครื่องผู้ใช้เท่านั้น

## ขึ้น GitHub Pages

1. สร้าง repository แบบ Public แล้วอัปโหลด `index.html` และ `README.md`
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## แกน X: การเงิน

กรอกรายได้สุทธิ หนี้ประจำ ค่าจำเป็น ไลฟ์สไตล์ (ออม = ส่วนที่เหลือ)

คะแนนฐานจากอัตราการออม = (รายได้ − รายจ่าย) ÷ รายได้ แปลงแบบเส้นตรงระหว่างจุด:

| อัตราการออม | −20% | 0% | 5% | 10% | 20% | 30% | 50%+ |
|---|---|---|---|---|---|---|---|
| คะแนน | −10 | −6 | −3 | **0** | +4 | +7 | +10 |

ตัวปรับตามเงินสำรอง (เงินสำรอง ÷ (หนี้ + ค่าจำเป็น)): ต่ำกว่า 1 เดือน −2 · 1–3 เดือน −1 · 3–6 เดือน 0 · 6 เดือนขึ้นไป +1 แล้วจำกัดผลสุดท้ายที่ −10 ถึง +10

เงินสำรองที่ควรมี = (หนี้ + ค่าจำเป็น) × 3 / 6 / 12 เดือน ตามสถานการณ์

ชุดสัดส่วนเป้าหมาย: มาตรฐาน (หนี้+จำเป็น ≤50%, ไลฟ์สไตล์ ≤30%, ออม ≥20%) หรือรายได้น้อย (≤65%, ≤20%, ≥15%) และเตือนเมื่อหนี้ต่อรายได้เกิน 30% / 40%

## แกน Y: คุณภาพงาน

9 ด้าน ด้านละ 3 ข้อ ตอบ −2 ถึง +2 คะแนนด้าน = ค่าเฉลี่ย × 5 (ได้ −10 ถึง +10) คะแนน Y = ค่าเฉลี่ยถ่วงน้ำหนักตามความสำคัญที่ผู้ใช้เลือก 1–5

- ด้านที่ได้ต่ำกว่า −6 แสดงคำเตือนแยก
- เกณฑ์ที่ไม่ควรยอมรับ 4 ข้อ แสดงคำเตือนแยกจากคะแนน
- เส้นแบ่งอยู่ที่ 0 โซนก้ำกึ่ง ±1.5
